# Screenplay scene formatting

Use these conventions when writing the pivotal scene, so it reads like a
real script excerpt rather than a prose paragraph:

**Slugline** (scene heading) — one line, all caps:
`INT./EXT. LOCATION - TIME OF DAY`
- `INT.` (interior) or `EXT.` (exterior), never both
- Location as specific as the story needs, but no more ("INT. ABANDONED
  WAREHOUSE - NIGHT", not "INT. THE BUILDING")
- Time of day is conventionally `DAY`, `NIGHT`, `DAWN`, `DUSK`, or
  `CONTINUOUS` — not an exact clock time

**Action lines** — present tense, third person, only what's seen or heard:
- Short paragraphs (2-4 lines), one beat of action per paragraph
- No interior thoughts, no backstory exposition dumped into description —
  if it can't be filmed or heard, it doesn't belong in an action line
- Character names in CAPS on their first appearance in the scene

**Dialogue** — character name (caps) on its own line, then the line:
- Keep it terse; subtext over on-the-nose statement of feelings
- A parenthetical (one line, lowercase, in parentheses under the name)
  only when the delivery genuinely isn't clear from context — don't use it
  to state emotion the dialogue itself should already convey

**Structure of one scene**: slugline, then alternating action/dialogue
blocks, building to the scene's turn (the moment that changes what the
audience or a character knows), then out.

Do not apply this formatting to the synopsis, logline, or character
profiles — those stay prose. This is specifically for the scene itself.
