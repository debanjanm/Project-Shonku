# Project Shonku Overview

Project Shonku is an AI application platform, not a single chatbot. The Chat
application is the first app built on top of the platform — future apps can
be added later without rearchitecting the core.

## Core Philosophy

Project Shonku should feel like Linear, VS Code, ChatGPT, Cursor, and Notion
combined: clean, fast, and free of visual clutter. Every feature is
intentional.

## Knowledge Bases, Not Uploads

Unlike typical AI chat products, users do not upload their own files.
Instead, administrators curate Knowledge Bases (KBs) — collections of
approved, versioned content. Users simply pick which Knowledge Base they
want to chat with. This keeps answers grounded in trusted, reviewed content
instead of arbitrary uploaded documents.

Knowledge Base administration (creating, editing, and publishing KBs) is a
future phase. In the MVP, KBs are seeded from local content by the team.
